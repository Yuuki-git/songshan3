# MiniMax H3 单卡算子优化结果

以下为2026年10月16日至17日、固定官方源码与海光gfx906环境中的算子测量。统一入口复跑后，以新目录中的原始数据和汇总为准。全部结果属于单算子或逐元素子图，尚无完整H3 FL2VA或模型端到端收益结论。

## 基线与实现

基线为原始InfiniCore infiniop HYGON。五种RMSNorm组合为FP16/FP16、FP16/FP32、BF16/BF16、BF16/FP32、FP32/FP32，前者为输入输出，后者为权重。两侧经同一Core API比较。原始Core/LM及官方脚本不修改，新增设备计算全部由九齿生成。

二维RMSNorm按每程序一行处理128个元素，num_warps=1、num_stages=1。平方/求和用FP32，每行标量的加epsilon、开方和取倒数用FP64，再以FP32缩放与乘权重。FP64是当前工具链开方相关数值问题的已验证处理，编译根因仍未定位。

三维实现直接保持token/head索引、Q/K存储偏移和三维stride。56头的QKV切片输入stride为[21504,128,1]，不能连续展平。使用(1,1,128) tile，主验收选择内部[1,128] arrangement；守卫不满足时回退原实现。

融合面向宽度5376的三维AdaLN与门控残差，tile=(1,1,256)。保留调制表6W的token步长，FP16/BF16每个原始运算后转换回原精度，JIT/HIP AOT显式enable_fp_fusion=False。两个AdaLN和两个残差组成的逐元素子图由原始10次启动合并为4次。支持原地输出，部分重叠输出提前拒绝，空输入不启动。

## 正确性与范围

| 项目 | 验证结果 |
| --- | --- |
| 二维RMSNorm | 75组四路径；40组冻结用例，其中20组九齿、20组宽维原实现；修改输入后的Core列表重放 |
| 三维RMSNorm | 40项候选；40组四路径、160输出；20项补充；独立C++；15组实际HIP图 |
| AdaLN与门控残差 | 28组五路径、140输出逐位一致；28项补充；独立C++；18组配对与重放；4项部分重叠拒绝 |

RMSNorm参考为CPU float64再转换到目标精度，逐元素使用abs误差≤atol+rtol×abs(reference)。FP16为atol=rtol=2e-3，BF16为1e-2，FP32为atol=1e-5、rtol=1e-4。融合要求atol=rtol=0，保持逐运算舍入，输入保持与输出保护区均验证。

融合两次验收失败被保留：FP32原链参考需符合Core AddOp<float>的向负无穷舍入；不同形状广播由原始描述符拒绝，后续用等形状expand零步长视图验证原有契约。修正只涉及新增参考或验收输入，没有改原始Core或放宽容差。

当前单卡gfx906、固定宽度128/5376的结果不覆盖所有别名、并发注册、context销毁重建、多卡和其他架构。融合计时独立提供归一化与分支输出，真实模型共享调制表的局部性以及RMS/MHA/MLP整体计算仍需接入后验证。Core graph=false的列表重放与实际HIP图分别记录；事件时间不等于纯内核时间。
